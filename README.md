Entry for the [One Emoji, One Smile](https://make.fun/c/u-0xkianno-one-emoji-one-smile-5470751f) competition on make.fun.

The program (`main.ts`) writes exactly one emoji to `/output/entry.txt`:

🌞

A smiling sun: warm at first glance, universal, chosen rather than the
default smiley, and right for a stranger — no irony, intimacy or in-joke.

Deterministic and offline: no input, no randomness, no network, no time.
Two runs always produce byte-identical output.

## Run

```sh
node main.ts
cat /output/entry.txt
```
